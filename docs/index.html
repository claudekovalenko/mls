GitHub access token (needed once, to save changes)

Create a fine-grained GitHub token scoped to only this repo. Under "Permissions" click + Add permissions and add:

  • Contents → Read and write (required — lets it save houses/criteria)
  • Actions → Read and write (lets it instantly trigger price/beds/baths/photo auto-fill right after you add a house; without it, houses still get filled in on the next scheduled run, within 2 hours)
