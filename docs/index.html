Database

Connected to the House Finder database, built into the app. There is nothing to set up and nothing that can disconnect — this works on every device you open it on.

The background search and the emails run in GitHub Actions, so they need their own credentials — at github.com → Settings → Secrets → Actions: SUPABASE_URL and SUPABASE_SERVICE_KEY (the service key, not the one in the app: the worker writes rows).
