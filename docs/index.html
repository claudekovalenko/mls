Setup

Connect the database

Supabase (Postgres) holds the searches and the houses. Paste your project URL and its anon public key — both are stored only in this browser and sent only to your own Supabase project.

Where do I get these?

supabase.com → your project → Settings → API. The Project URL and the anon public key are both on that page.

First time: open the SQL editor and run supabase/schema.sql from this repo. That builds the tables and the access rules the app needs.

The anon key is safe in a browser — it is a public key, and row-level security in the schema decides what it can actually touch.

Still on Airtable?

The old backend. Connect it here to keep working until the data is migrated — once a Supabase project is connected above, the app uses that instead.

Connection

The background search and the emails run in GitHub Actions, so they need their own copy of the credentials — at github.com → Settings → Secrets → Actions. Supabase needs SUPABASE_URL and SUPABASE_SERVICE_KEY (the service key, not the anon key: the worker writes rows).

Photos

The listing feed carries no photos, and the listing sites block fetching theirs. So every card carries a See it from the street tile that opens the Google Maps curb view — no key, no account, no card on file. For a fixer hunt the kerb view is close to the point, since a tired roof and an overgrown yard show from the road.

Optional: pasting a Google Maps key below swaps that tile for the photo itself, inline on the card. Google requires billing enabled on the project to issue a key — a card on file, even though this volume stays inside the free 5,000/month. Leave it blank to keep everything free.
